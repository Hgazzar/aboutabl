٣) مثال عملي: سؤال توصيل (Matching) — ما معنى answer2.1 … answer2.8؟

الفكرة: الطالب يوصّل كل عنصر في العمود الأول بالعنصر المناسب في العمود الثاني.

العمود الأول (answer1 … answer8)

  • ١ → القاهرة
  • ٢ → الرياض
  • ٣ → بغداد
⟷ يوصّل الطالب بينها

العمود الثاني (answer2.1 … answer2.8)

  • أ → مصر
  • ب → السعودية
  • ج → العراق

كيف تكتبها في الإكسل؟

… answer1 answer2 answer3 answer2.1 answer2.2 answer2.3
… القاهرة الرياض بغداد مصر السعودية العراق
  • answer1 = القاهرة ← يوصّل بـ answer2.1 = مصر
  • answer2 = الرياض ← يوصّل بـ answer2.2 = السعودية
  • answer3 = بغداد ← يوصّل بـ answer2.3 = العراق

صورة توضيحية:

حقل corAnswer يحدد التوصيلة الصحيحة (مثل: 1:1,2:2,3:3 أو حسب شكل النظام). إذن answer2.1 … answer2.8 هي نصوص العمود الثاني فقط، وليست «أي إجابة من عدة إجابات تقبل».

٤) ملخص سريع

  • MCQ / TF / SHN: استخدم question, corAnswer, answer1…answer8 حسب الحاجة. اترك answer2.1 … answer2.8 فارغة.
  • Matching: answer1…answer8 = العمود الأول، answer2.1…answer2.8 = العمود الثاني، وcorAnswer يحدد التوصيل الصحيح.
  • الأعمدة A, B, C يجب أن تكون أرقام (معرّفات المادة والوحدة والدرس).
