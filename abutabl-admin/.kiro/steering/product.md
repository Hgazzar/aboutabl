# Product Overview

This is a Learning Management System (LMS) admin application for educational institutions. The platform manages schools, students, employees (teachers/staff), subjects, grades, classes, and educational content.

## Core Features

- School management with multi-school support
- User management (students, employees, roles)
- Subject and curriculum management
- Educational content delivery (lessons, units, activities)
- Assessment tools (quizzes, assignments, worksheets)
- Interactive learning (games, SCORM content)
- Question bank for assessments
- File management system
- Reporting and analytics
- Ticketing system
- Role-based permissions and access control

## User Types

- Admin users with granular permissions
- Teachers/employees with subject and class assignments
- Students enrolled in classes and subjects
- School-level administrators

## Internationalization

The application supports both English and Arabic languages with RTL support for Arabic.
